# HR Analytics & Employee Attrition Dashboard | Power BI

## 1. Purpose

Developed an interactive Power BI dashboard to analyze employee attrition and identify workforce trends across demographics, education, salary, departments, job roles, and employee experience. The dashboard provides actionable insights to support HR decision-making and employee retention strategies.

## 2. Tech Stack

- **Power BI:** Used to build the interactive HR Analytics dashboard and analyze employee attrition.
- **Microsoft Excel/CSV:** Used as the source dataset containing employee and HR-related information.
- **Power Query:** Used to clean, transform, and prepare the employee data for analysis.
- **DAX:** Used to create measures and calculate KPIs such as attrition rate, employee count, and averages.
- **Data Visualization:** Used charts, graphs, and KPI cards to present HR trends clearly.
- **KPI Analysis:** Analyzed key metrics such as attrition, attrition rate, average salary, and average years at company.

## 3. Data Source

HR Employee Dataset (CSV) containing 1,480 employee records and 38 attributes related to employee demographics, job roles, compensation, satisfaction, experience, and attrition.

## 4. Features & Highlights

-Analyzed **1.48K employee records**
- Analyzed **237 employee attritions**
- Calculated **16.1% overall attrition rate**
- Analyzed attrition by **age, gender, education, salary slab, department, and job role**
- Analyzed employee experience based on **years at company**
- Added interactive department filters for **HR, R&D, and Sales**
- Created KPI cards for **employee count, attrition, attrition rate, average salary, and experience**
- Identified **high-attrition employee segments**
- Created interactive visualizations to support **data-driven HR decision-making**
